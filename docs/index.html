Architecture

工作原理

po0「鸡险」机器防火墙仅放行白名单内的最近来源网段。po0fw 让你的路由器与随身设备自动维护出口记录：

01

双通道触发

结合网络切换事件（WAN 重拨 / Wi-Fi 蜂窝切换即时触发）与 10–15 分钟定时巡检，兼顾秒级响应与静默换 IP 兜底。

02

官方 IP 直连上报

直接向官方 IP 证书端点发起 HTTPS POST 请求，客户端无需探测公网 IP，普通按域名分流的代理也不会误劫持。

03

服务端 /24 幂等加白

服务端自动提取来源 IP 所在的 C 段（/24）写入白名单。同一网段重复请求完全幂等，不占新坑、不推进淘汰队列。

04

常驻槽位与 FIFO 自愈

关键家宽出口可用 @0 钉死常驻；其余流动设备共享剩余 FIFO 坑位，偶被挤出也能在下个周期自动补回。

Quick Setup

配置与安装

在 po0 控制台机器详情页「防火墙」卡片点击「复制添加脚本」，提取其中 pgnfw_ 开头的凭证填入下方工作台。

填入你的防火墙 Token

1

SSH 登录 OpenWrt / Kwrt 软路由，执行一键安装

自动部署主程序至 /usr/bin/po0fw，生成 0600 权限配置并立即执行首次加白校验：

OpenWrt / Kwrt · SSH 
curl -fsSL https://raw.githubusercontent.com/w0ven/po0fw/main/openwrt/install-openwrt.sh -o /tmp/i.sh
PO0FW_TOKENS="pgnfw_你的token" sh /tmp/i.sh
2

双触发已就绪 · 日常运维命令

已配置 hotplug WAN 重拨秒级加白（自动过滤纯 IPv6 接口防并发踩踏）与 cron 每 10 分钟兜底。随时可执行 po0fw status 只读查看白名单，或查看带时间戳的运行日志 /tmp/po0fw.log。

为什么最推荐部署在软路由：只有主路由能第一时间捕获 PPPoE / 光猫重拨事件；且家庭局域网内所有连 Wi-Fi 的手机与电脑天然共享该出口，无需每台终端重复安装。建议配合 @0 固定槽位使用。
1

Linux / macOS — 终端一键安装

Linux root 自动注册 po0fw.timer（systemd）；macOS 与非 root 普通用户自动安装至 ~/.local/bin/po0fw 并写入 crontab（每 10 分钟）：

Linux / macOS · POSIX Shell 
curl -fsSL https://raw.githubusercontent.com/w0ven/po0fw/main/install-linux.sh | PO0FW_TOKENS="pgnfw_你的token" sh
2

Windows — 管理员 PowerShell 一键安装

注册后台静默计划任务（wscript 无窗口启动，彻底告别黑框闪烁）：每 10 分钟巡检 + 网络连接事件（EventID 10000）自动触发：

Windows · PowerShell (Administrator) 
irm https://raw.githubusercontent.com/w0ven/po0fw/main/windows/install-windows.ps1 -OutFile i.ps1
powershell -ExecutionPolicy Bypass -File i.ps1 -Tokens "pgnfw_你的token"
常用管理命令：运行 po0fw 立即加白 · po0fw status 只读查询状态 · po0fw uninstall 一键卸载（Windows 运行 powershell -ExecutionPolicy Bypass -File "$env:ProgramData\po0fw\po0fw.ps1" -Status 查看状态）。

FAQ

常见问题

Wi-Fi 保持连接未断开，但运营商静默重拨换了公网 IP，能及时更新吗？
手机和电脑端无法直接感知路由器上游的静默重拨，此时由 10–15 分钟定时任务兜底更新；且家宽同地区重拨常落在同一 /24 网段内，无需重新写入。若希望重拨后数秒内无感恢复，最推荐在 OpenWrt 软路由上安装——路由器 hotplug 可直接捕获 WAN 接口地址变更事件立即上报。
固定槽位 @N 是什么？如果遇到 403 槽位冲突怎么处理？
白名单默认上限 5 个网段，满额后按写入时间先进先出（FIFO）淘汰最旧记录。在 Token 后追加 @0（支持 0–4）即可将该出口钉在 0 号固定槽位，永不参与淘汰。注意同一网段不能同时占用两个不同的固定槽位；若更换槽位号时报 403 槽位冲突，前往 po0 控制台防火墙卡片手动删除旧槽位记录即可。
开启代理软件时，会把代理节点的出口 IP 误加进白名单吗？
常规分流模式下不会：加白接口直接请求官方 IP 124.221.69.228，不经过域名解析与域名规则匹配，且本仓库全部 6 款代理客户端模块均已内置 IP-CIDR,124.221.69.228/32,DIRECT,no-resolve 直连规则。若在 PC 或路由器使用全局 TUN / 透明代理接管所有 IP 流量，请确认规则中包含该直连条目（OpenClash 等软路由插件请确认路由器本机流量绕过代理）。
在网页工作台填入 Token 安全吗？
Token 等同于对应机器的白名单添加凭证，请勿公开贴在群聊或公开仓库中。本页面为托管于 GitHub Pages 的纯静态前端，所有命令拼接均在你的浏览器本地完成并仅缓存在本地 localStorage（随时可点「清空」抹除），不会向任何第三方服务器发送你的 Token。
如何干净地卸载？
• OpenWrt / Linux / macOS / Termux：直接执行 po0fw uninstall（非 root 且未加入 PATH 时执行 ~/.local/bin/po0fw uninstall），脚本会自动停用并移除 systemd timer / crontab / hotplug 触发器、配置文件与程序本身。
• Windows：在管理员 PowerShell 执行 irm https://raw.githubusercontent.com/w0ven/po0fw/main/windows/install-windows.ps1 -OutFile u.ps1; powershell -ExecutionPolicy Bypass -File u.ps1 -Uninstall 即可一键清理计划任务与目录。
• iOS / Android：在对应代理客户端中删除模块，或在 MacroDroid / 快捷指令中删除对应自动化规则即可。
